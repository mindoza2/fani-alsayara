# فني السيارة — Car Technician

تطبيق ويب (PWA) لفحص وتشخيص السيارات عبر محوّل OBD-II من نوع **ELM327 / KONNWEI KDIAG** باستخدام **Web Bluetooth**.

## التشغيل
افتح رابط الاستضافة (GitHub Pages) في متصفح يدعم Web Bluetooth:
- **ويندوز / أندرويد:** Google Chrome
- **آيفون:** متصفح Bluefy (سفاري لا يدعم Web Bluetooth)

ثم اضغط «الاتصال» واختر محوّل KDIAG. يوجد **وضع تجريبي** لتصفّح الواجهة بدون قطعة.

## القدرات
اتصال واكتشاف بروتوكول تلقائي، خريطة شبكة الكمبيوترات، فحص شامل، قراءة الأعطال وكل أوضاع OBD القياسية، فحص الجاهزية، بيانات حية بعدّادات، تشخيص موجّه، مسجّل مشوار، مخططات كهربائية تفاعلية، خدمات وتحكّم ثنائي الاتجاه (حسب ما يتيحه الكمبيوتر، بشفافية)، ومساعد ذكاء اصطناعي.

> ملاحظة: البرمجة/التشفير مرحلة لاحقة مستقلة. كل معلومة تحمل مستوى ثقة ظاهر (موثوق / أفضل جهد / تقديري).
